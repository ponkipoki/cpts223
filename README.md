# Does machine processing power affect execution time?
# Yes. If the machine has a higher processing power, then the execution time of code/instructions would generally be faster.

# Which performs better: std::list or std::vector? Under what conditions?
# As N gets larger, std::vector performs better. That is because it does not have to traverse through itself linearly like a list does.

# How does N impact runtime compared to M?
# Regardless of what M you have, you still have to do the same amount of eliminations, which is N - 1. However, as N gets bigger, the overall
